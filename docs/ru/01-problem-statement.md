# 📘 Постановка задачи и научная гипотеза

> **Классическая задача теории управления и энергетики.** Ограничение суммы идеально ложится на "пропускную способность шины", а взаимное исключение — на "защиту от короткого замыкания".

---

## 1. Формальная постановка задачи

**Название кейса:** Реконфигурация микро-энергосети (Smart Grid) в аварийном режиме с помощью квантовой оптимизации.

**Контекст (для УТС):**
На промышленном объекте произошла авария на главной подстанции. Имеется 4 резервных линии питания (генераторы/ИБП). Система автоматического ввода резерва (АВР) должна экстренно выбрать конфигурацию подключения.

**Цель:** Выбрать линии так, чтобы минимизировать суммарные потери электроэнергии (целевая функция).

**Жесткие ограничения автоматики:**
1. 🔹 **Баланс мощности (Равенство):** Ровно 2 линии должны быть активны одновременно (`Σx_i = 2`). Меньше — не хватит мощности цехам, больше — сгорит резервная шина распределения.
2. 🔸 **Топологический конфликт (Неравенство):** Линии `0` и `3` запитаны от одного поврежденного трансформатора. Их одновременное включение приведет к короткому замыканию (`x₀·x₃ = 0`).

**Почему это релевантно направлению 27.03.04 (УТС):**
Задача моделирует критическую проблему диспетчерского управления — поиск безопасного и оптимального управляющего воздействия в условиях жестких ограничений. С ростом числа узлов в Smart Grid сложность классического полного перебора растет экспоненциально. Проект исследует потенциал квантовых сопроцессоров (QPU) как будущей альтернативы ПЛК (программируемым логическим контроллерам) для мгновенного решения NP-трудных задач диспетчеризации.

## 2. Математическая модель (QUBO)

### Переменные
$$x_i \in \{0,1\}, \quad i = 0,1,2,3$$
где $x_i=1$ — линия включена, $x_i=0$ — линия отключена.

### Целевая функция (потери на линиях)
$$\min \; f(\mathbf{x}) = \sum_{i=0}^{3} c_i x_i, \quad \mathbf{c} =[1.2,\; 0.8,\; 1.5,\; 0.9]$$
*(Коэффициенты отражают сопротивление/стоимость эксплуатации конкретной линии).*

### Ограничения → штрафные члены
1. **Предотвращение перегрузки/недогрузки шины** $\sum x_i = 2$:
   $$P_1 \left( \sum_{i=0}^3 x_i - 2 \right)^2$$
2. **Предотвращение КЗ трансформатора** $x_0 x_3 = 0$:
   $$P_2 \cdot x_0 x_3$$

### Итоговый Гамильтониан энергии
$$H(\mathbf{x}) = \sum_{i} c_i x_i + P_1 \left( \sum_{i} x_i - 2 \right)^2 + P_2 x_0 x_3$$
Данная функция транслируется в квантовые вентили алгоритма QAOA, где поиск минимума энергопотерь заменяется поиском основного квантового состояния системы.

## 3. Научная гипотеза и методология

### ✅ Гипотеза
> *«В задачах дискретного управления с жесткими ограничениями (микро-сети), гибридный квантовый алгоритм QAOA (даже при глубине $p=1$ на устройствах класса NISQ) способен выделять оптимальное управляющее воздействие. При этом смена парадигмы — от пошагового перебора к квантовой интерференции — доказывает принципиальную возможность применения QPU в системах реального времени в будущем, когда аппаратные ошибки кубитов будут снижены.»*

### 📊 Критерии подтверждения
- [x] Теоретическая QUBO-матрица корректно переводится в физику квантового симулятора (штрафы работают).
- [x] Квантовый алгоритм находит глобальный оптимум (отклонение $\epsilon \le 10\%$).
- [x] Ограничения безопасности (сумма=2, отсутствие конфликтов) соблюдаются в значительной доле измерений (с учетом неоптимизированных параметров $\gamma, \beta$).
- [x] Автоматика скрипта укладывается в 60-секундный лимит исполнения на Origin Cloud.

## 4. Конфигурация контроллера (`config.json`)

```json
{
  "n_vars": 4,
  "objective_costs": [1.2, 0.8, 1.5, 0.9],
  "equality_constraints": [
    {
      "indices": [0, 1, 2, 3],
      "target_sum": 2,
      "penalty": 50.0
    }
  ],
  "inequality_constraints": [
    {
      "indices": [0, 3],
      "penalty": 100.0,
      "type": "mutual_exclusion"
    }
  ],
  "qaoa_params": {
    "p": 1,
    "gamma": 0.5,
    "beta": 0.3
  }
}
```

🔍 **Физический смысл штрафов:**
- $P_1=50.0$: Угроза отключения целой секции завода из-за неверной мощности оценивается системой автоматики намного "дороже", чем потери на проводах (1.2 - 1.5).
- $P_2=100.0$: Короткое замыкание — критическая авария. Вероятность этого состояния квантовый алгоритм должен подавлять максимально жестко.

## 5. Тестирование и ожидаемые результаты

Анализ энергетического ландшафта показывает следующие состояния (из 16 возможных):

| Состояние $x$ (Линии) | Энергия системы (H) | Статус (Автоматика) | Причина отклонения |
|------------------------|---------------------|---------------------|-------------------|
| `0 1 0 1`              | **1.700**           | 🏆 **Оптимум**      | Идеальный баланс, линии 1 и 3. |
| `1 1 0 0`              | 2.000               | ✅ Допустимо        | Потери выше оптимума (2.0 > 1.7). |
| `0 1 1 0`              | 2.300               | ✅ Допустимо        | Потери выше оптимума (2.3 > 1.7). |
| `1 0 0 1`              | 102.100             | ❌ Авария (КЗ)      | Нарушено ограничение 0↔3 (Штраф 100). |
| `0 0 0 1`              | 50.900              | ❌ Авария (Мощность)| Активна только 1 линия (Штраф 50). |

📌 **Ожидания от кванта:**
Из-за глубины $p=1$ и фиксированных неоптимизированных углов $\gamma, \beta$, мы увидим "размытое" распределение. Квантовая система будет выдавать ошибки (аварийные состояния), но среди валидных решений пик вероятности уверенно скопится вокруг глобального оптимума `0101`, что докажет работоспособность квантовой физики для решения логических задач УТС.
